# Project-FastReactPizza

## 1. Giới thiệu dự án 
Đây là dự án đc tạo ra trong quá học tập react nhằm thể hiện các kĩ năng đã học, không phải sản phẩm cá nhân<br>
This is learning projects developed during my React studies to showcase the skills I've learned, It is not personal projects.<br>
Fast React Pizza là 1 dựa án đặt pizza đơn giản, nơi người dùng có thể dễ dàng đặt và quản lý đơn hàng của mình

## 2. Hình ảnh giao diện

## 3. Chức năng
 .Bỏ những cái bánh pizza vào cart
 .Thanh toán các sản phẩm trong cart
 .Xuất hoá đơn thanh toán
 .Có thể tìm kiếm các order của mình sau khi hoàn thành

## 4. Công nghệ sử dụng
 . JavaScript<br>
 . React<br>
 . React-router-dom<br>
 . React-dom<br>
 . React-redux<br>

## 5. Cách cài đặt
 ### B1:
 git clone https://github.com/kothichdangky/Project-FastReactPizza.git<br>
 cd fast-react-pizza<br>

 ### B2:    
 npm install

 ### B3: 
npm run dev<br>
Truy cập http://localhost:5173 để sử dụng ứng dụng.
